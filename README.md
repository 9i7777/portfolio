# ⚡ Персональное портфолио веб-разработчика // 9i7777

Современный, быстрый и отзывчивый сайт-портфолио в концепции **"Dev Studio & Interactive Lab"**.
Создан с нуля без тяжелых фреймворков и лишних зависимостей.

---

## 🌟 Ключевые особенности
1. **Светлая эстетичная дизайн-система (по умолчанию)** с возможностью переключения в тёмный режим (кнопка в шапке или команда `theme` в консоли).
2. **Интерактивный терминал разработчика (Dev Console)** в Hero-секции:
   - Поддерживает ввод команд: `help`, `about`, `skills`, `projects`, `contact`, `theme`, `clear`, `time`, `sudo`.
   - Быстрые кликабельные чипы-команды для удобного запуска на смартфонах и ПК.
3. **Реестр проектов и лаборатория**:
   - 3 интерактивных концептуальных кейса (Kanban task board, Canvas mesh generator, Crypto ticker).
   - Слот-карточки **"In Development"** для демонстрации проектов в разработке.
4. **Матрица навыков**:
   - Наглядная разбивка по направлениям: *Core Web*, *APIs & Библиотеки*, *Инструменты & Процесс*.
5. **Интерактивная песочница (Canvas Playground)**:
   - Живой генератор волн с ползунками (оттенок Hue, скорость, плотность) и кнопкой копирования готового CSS-кода градиента.
6. **Контакты и быстрая связь**:
   - Копирование Telegram (`@danilmam`), GitHub (`9i7777`) и Email в один клик со всплывающими тост-уведомлениями.
   - Форма быстрой отправки сообщений с валидацией.

---

## 🚀 Как открыть сайт на своём компьютере

Вам **не нужны** Node.js, сборщики или сложные команды:
1. Просто дважды кликните по файлу **`index.html`** в проводнике Windows — он откроется в любом браузере (Chrome, Edge, Firefox, Opera, Yandex).
2. Если вы используете **VS Code**, можете установить расширение **Live Server** и нажать *"Go Live"* в правом нижнем углу.

## 🌐 Как бесплатно выложить сайт в интернет

### Вариант 1: GitHub Pages (Рекомендуется)
1. Создайте репозиторий на [GitHub](https://github.com/new) с именем `portfolio` (или `9i7777.github.io`).
2. Загрузите файлы проекта в репозиторий.
3. Перейдите в **Settings** -> **Pages** -> выберите ветку `main` (или `master`) и папку `/(root)`.
4. Через минуту ваш сайт будет доступен по ссылке: `https://9i7777.github.io/portfolio`.

### Вариант 2: Vercel или Netlify
1. Зарегистрируйтесь на [Vercel](https://vercel.com) или [Netlify](https://netlify.com).
2. Перетащите папку с сайтом прямо в браузер — сайт сразу опубликуется с бесплатным SSL-сертификатом и быстрым доменом.
