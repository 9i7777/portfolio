Как добавить свой проект в портфолио?

Все проекты загружаются из одного файла: js/projects-data.js. Тебе не нужно переверстывать HTML-код! 

// Открой файл js/projects-data.js
// И просто добавь новый объект в массив PROJECTS:

{
  id: 4,
  title: "Название твоего проекта",
  category: "frontend", // frontend | tool | prototype
  status: "Ready",
  statusClass: "status-ready",
  description: "Что делает проект и какую задачу решает...",
  features: [
    "Первая ключевая фича",
    "Вторая ключевая фича",
    "Технология или интересная деталь"
  ],
  tags: ["HTML5", "CSS Grid", "JS ES6+"],
  demoUrl: "https://твое-демо.vercel.app",
  githubUrl: "https://github.com/9i7777/repo",
  colorAccent: "#2563EB",
  previewType: "kanban"
}

Карточка проекта с фильтрацией, тегами и модальным окном появится на сайте автоматически!
